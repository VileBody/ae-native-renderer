## Decision

`M15`, `M10`, and `M13` are not the current blockers for this batch:

- `TMP_020` stays exact and `STK_030` temporal contract stays green.
- `EFF_010` / `STK_010` Drop Shadow are already low-error.
- `EFF_050` Minimax is already low-error after the enum/radius/edge work.

`M11` Glow is the only module in this set with a meaningful isolated residual.
The accepted implementation change is to keep the existing `Glow Based On`
default branch but replace the old Glow-local box approximation with a
separable Gaussian approximation on the Frida-confirmed radius route:

```text
ir_gaussian_radius = glow_radius * 0.4
support_radius = ceil(ir_gaussian_radius * 2)
```

This is not final AE parity. It moves native Glow from "box approximation despite
IR_GaussianBlur evidence" to "Gaussian approximation on the recovered route".
