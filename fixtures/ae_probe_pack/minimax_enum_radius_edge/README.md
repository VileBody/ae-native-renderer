# AE Minimax Enum/Radius/Edge Probe Pack

Runnable After Effects probe pack for resolving `ADBE Minimax` enum and edge
semantics:

- operation `0001 = 1..4` on both impulse and ramp sources
- channel `0003 = 1..6` on distinct RGBA lane primitives
- direction `0004 = 1..3` on horizontal/vertical impulse lines
- fractional radius `0002 = 0.25, 0.49, 0.5, 0.51, 1.49, 1.5, 1.51`
- boundary/edge policy `0005 = 0/1`

The pack is independent from `fixtures/ae_probe_pack/minimax` and does not
modify that older probe.

## Files

- `manifest.json` defines the sources, cases, output paths, and analysis ROIs.
- `assets/primitives/*.png` are deterministic 128x128 source primitives.
- `jsx/build_minimax_enum_radius_edge_project.jsx` imports assets, builds AE
  comps, queues renders, and dumps effect property metadata.
- `scripts/measure_minimax_enum_radius_edge.py` measures rendered PNGs and
  writes JSON/CSV summaries.

## Generate Assets

The PNG primitives are generated by the measurement script:

```text
python3 fixtures/ae_probe_pack/minimax_enum_radius_edge/scripts/measure_minimax_enum_radius_edge.py \
  --pack fixtures/ae_probe_pack/minimax_enum_radius_edge \
  --generate-assets
```

## Build And Render In AE

1. Open After Effects.
2. Run `File > Scripts > Run Script File...`.
3. Select:

```text
fixtures/ae_probe_pack/minimax_enum_radius_edge/jsx/build_minimax_enum_radius_edge_project.jsx
```

The script sets the project baseline to 8 bpc, imports the generated PNG
assets, creates one comp per manifest case, queues PNG sequence renders, and
writes:

```text
fixtures/ae_probe_pack/minimax_enum_radius_edge/ae_goldens/metadata/minimax_enum_radius_edge_property_dump.json
```

Queued renders target:

```text
fixtures/ae_probe_pack/minimax_enum_radius_edge/ae_goldens/png/<case_id>/<case_id>_[#####].png
```

The JSX first tries the `PNG Sequence with Alpha` output module template, then
falls back to `PNG Sequence` if the alpha template is unavailable.

## Measure Renders

After AE renders at least the first frame for each queued case, run:

```text
python3 fixtures/ae_probe_pack/minimax_enum_radius_edge/scripts/measure_minimax_enum_radius_edge.py \
  --pack fixtures/ae_probe_pack/minimax_enum_radius_edge
```

Outputs:

```text
fixtures/ae_probe_pack/minimax_enum_radius_edge/ae_goldens/metadata/minimax_enum_radius_edge_measurements.json
fixtures/ae_probe_pack/minimax_enum_radius_edge/ae_goldens/metadata/minimax_enum_radius_edge_measurements.csv
fixtures/ae_probe_pack/minimax_enum_radius_edge/ae_goldens/metadata/minimax_enum_radius_edge_semantics.csv
```

The JSON includes full detail, `measurements.csv` is one row per case, and
`semantics.csv` flattens the derived sections:

- `stage_order`: case order and measurement pipeline
- `operation_order`: signatures for `0001 = 1..4` on impulse/ramp
- `channel_lane_effects`: RGBA lane deltas for `0003 = 1..6`
- `orientation`: bbox/aspect classification for `0004 = 1..3`
- `radius_quantization`: pixel clusters for fractional radii
- `edge_policy`: edge-touch deltas for `0005 = 0/1`

## Local Self-Test

The self-test synthesizes dummy PNG renders with a simple local Minimax model
and then runs the same measurement path:

```text
python3 fixtures/ae_probe_pack/minimax_enum_radius_edge/scripts/measure_minimax_enum_radius_edge.py \
  --pack fixtures/ae_probe_pack/minimax_enum_radius_edge \
  --generate-assets \
  --self-test
```

This does not validate AE semantics; it validates that the manifest, assets,
PNG discovery, JSON output, CSV output, and semantic reducers are runnable.

## 16/32 bpc Notes

The baseline probe is 8 bpc because PNG sequence renders are widely available
and easy to compare. For 16 or 32 bpc follow-up measurements, use the same case
matrix but change `app.project.bitsPerChannel` in the JSX to `16` or `32`, and
render with an installed output module that preserves higher precision, such as
TIFF/EXR if available in the local AE template set. Keep those outputs in a
separate render root and pass it with `--render-root`.
