# P2 Text Hinting Probe

Tiny single-frame AE probe pack for P2-B hinting/grid-fit/AA/subpixel evidence.

The pack intentionally renders isolated black-on-transparent glyphs with no
effects and no animation:

- `HNT_010..013`: `I`, 12 px, text-layer position fractions `0.00/0.25/0.50/0.75`.
- `HNT_020..023`: `H`, 24 px, same fractions.
- `HNT_030..033`: `W`, 96 px, same fractions.

The first intended remote run for this pass used job id prefix
`p2_hinting_20260507_231636`.
