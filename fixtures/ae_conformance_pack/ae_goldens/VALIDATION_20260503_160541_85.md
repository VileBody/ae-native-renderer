goldens. The first JSX version put a slate/title text layer inside every
per-case comp for the first ~0.45 seconds. Since the manifest includes early
frames for comparison, those frames are polluted by labels.

belong only to `master_conformance_reel`, which is for human preview.

Recommended action: rerender the pack with the updated
`jsx/build_conformance_project.jsx`, then import the new PNGs into
`ae_goldens/png/`.
